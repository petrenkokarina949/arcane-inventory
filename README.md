# Arcane Inventory

## Project Overview

Arcane Inventory is a Kotlin console application designed to manage magical ingredients, potions, recipes and inventory in a fantasy alchemy workshop.

The project aims to demonstrate object-oriented programming, Kotlin collections, lambdas, data persistence and unit testing.

## Planned Features

- Ingredient and potion management (CRUD).
- Potion recipe management.
- Potion crafting based on available ingredients.
- Inventory tracking and statistics.
- Search, filtering and sorting.
- Interactive console menu and input validation.
- Data persistence.
- Unit testing.

## Technologies

- Kotlin
- JDK 25
- Gradle
- IntelliJ IDEA
- Git and GitHub
- JUnit (planned)

## Planned Project Structure

- `models` - Data classes.
- `controllers` - Inventory management.
- `services` - Business logic.
- `persistence` - Data storage.
- `utils` - Input handling and validation.

## Getting Started

1. Clone the repository.
2. Open the project in IntelliJ IDEA.
3. Configure JDK 25 and synchronise Gradle.
4. Run the main function in `Main.kt`.
